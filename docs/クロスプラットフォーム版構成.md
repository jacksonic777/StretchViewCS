# クロスプラットフォーム版構成

## 目的

既存の Windows Forms 版を壊さずに、Windows 依存機能を切り離した macOS 対応版を別系統で育てる。

## 追加した場所

クロスプラットフォーム版は、リポジトリ直下の `StretchViewCS.CrossPlatform/` に配置する。

```text
StretchViewCS.CrossPlatform/
├── StretchViewCS.CrossPlatform.sln
├── README.md
├── StretchView.Core/
│   ├── StretchView.Core.csproj
│   └── ViewState.cs
└── StretchView.App.Desktop/
    ├── StretchView.App.Desktop.csproj
    ├── Program.cs
    ├── App.axaml
    ├── App.axaml.cs
    ├── MainWindow.axaml
    └── MainWindow.axaml.cs
```

## プロジェクトの役割

### StretchView.Core

OS に依存しない状態管理や設定モデルを置く。

現時点では、表示状態の土台として `ViewState` を追加している。

- 拡大率
- 回転角度
- 左右反転
- 上下反転
- グリッド表示状態

### StretchView.App.Desktop

Avalonia ベースのデスクトップ UI を置く。

Windows / macOS の両方で動かす前提のアプリ本体であり、WinForms や Win32 API には依存させない。

## 技術スタック

- .NET 9
- Avalonia 12.1.1
- Avalonia.Desktop
- Avalonia.Themes.Fluent
- Avalonia.Fonts.Inter

## ビルド方法

PowerShell から次を実行する。

```powershell
dotnet build .\StretchViewCS.CrossPlatform\StretchViewCS.CrossPlatform.sln
```

初期追加時点では、`0 警告 / 0 エラー` でビルドできることを確認済み。

## 既存 Windows 版との関係

既存の `StretchViewCS.sln` や WinForms 版のコードはそのまま残す。

クロスプラットフォーム版は別ソリューションとして扱い、既存 Windows 版のリリースや保守に影響しないようにする。

## 移植方針

Windows API 前提の実装は直接持ち込まない。

特に次の機能は、クロスプラットフォーム版では初期対象外とする。

- 操作投影
- 他ウィンドウ操作
- Win32 グローバルホットキー
- Windows スタートメニュー登録
- Inno Setup インストーラー

## 初期 MVP 候補

まずは、OS 依存が比較的少ない機能から載せる。

- 画像の読み込みと表示
- 拡大縮小
- 回転、反転
- グリッド表示
- 画像保存
- アプリ内注釈レイヤ

画面キャプチャは macOS の Screen Recording 権限や OS 別実装が必要になるため、MVP の後半で扱う。
