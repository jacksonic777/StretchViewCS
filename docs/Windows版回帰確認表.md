# Windows版 回帰確認表

## 目的

StretchViewCS の Windows 版で、変更後に最低限確認すべき機能を毎回同じ粒度で確認するための表を残す。

## 使い方

- 1 回のビルド確認につき 1 セット記録する
- `OK`、`NG`、`未確認` のいずれかを必ず記入する
- `NG` の場合は、不具合報告テンプレートへ切り出す
