## 未完了・要確認（概要）

詳細は [Delphi版移植の未完了項目.md](./Delphi版移植の未完了項目.md) を参照してください。

- **ホットキー**: 登録処理がコメントアウトのまま。HandleHotKey は実装済みだが、実際にはキーが登録されていない。
- **印刷**: PrintDialog とビットマップ取得まで実装。実際の印刷（PrintDocument で出力）は未実装。
- **画像回転の最適化**: LockBits 等による低レベル最適化は未実装（簡易版で動作）。
- **表面レイヤメニュー**: `pbMainView` 上の注釈レイヤとして利用可能。
- **操作投影モード**: 他アプリ依存が強いため、安定版では UI とホットキーから外している。
- **ヘルプファイル（.hlp）**: 起動処理はあるが、Windows 10/11 では WinHlp32 が標準でない場合あり。
- **スタートメニュー登録**: 設定フォームでのショートカット作成の有無は要確認。

## 技術的な課題（残り）

### 1. パフォーマンス
- **現状**: Graphics を使用した簡易的な画像回転で動作
- **課題**: 必要に応じて `LockBits()` による低レベル最適化が可能

### 2. ホットキー
- **現状**: 登録処理がコメントアウトのため、ホットキーは無効
- **課題**: 他アプリとの競合を考慮したキー割り当てとエラーハンドリング

### 3. 印刷
- **現状**: ダイアログとビットマップ取得まで実装済み
- **課題**: PrintDocument による実際の印刷出力の実装
