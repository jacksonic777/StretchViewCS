# リリース手順

## 目的

`StretchViewCS` の Windows 版について、少なくとも次を再現可能にすることを目的とする。

- `Release` ビルドが通ること
- 配布対象ファイルだけを抽出したパッケージを作れること
- その後にインストーラー作成へ進める前提が明確であること

## 現在の前提

- プロジェクトは `.NET Framework 4.8` の `WinForms` アプリである
- `Visual Studio 2022` の `MSBuild.exe` で `Release` ビルドが通る
- 配布対象は `StretchViewCS.exe` 系と `help/`、必要 DLL に限定する
- `.pdb` は通常配布に含めない

## 配布対象

現時点での通常配布対象は次とする。

- `StretchViewCS.exe`
- `StretchViewCS.exe.config`
- `System.Configuration.ConfigurationManager.dll`
- `help/index.html`
- `help/style.css`

通常配布対象から外すものは次とする。

- `StretchViewCS.pdb`
- `obj/` 配下の中間生成物
- 旧成果物や用途不明ファイル

## 自動パッケージ作成

リポジトリには、`Release` ビルドと zip パッケージ作成を行うスクリプトを追加している。

- [Create-ReleasePackage.ps1](/C:/repos/StretchViewCS/tools/Create-ReleasePackage.ps1)

このスクリプトは次を行う。

1. `Release` ビルドを実行する
2. `bin/Release/net48` から必要ファイルだけを抽出する
3. `artifacts/release/StretchViewCS-<version>/` を作る
4. 同内容の zip を `artifacts/release/StretchViewCS-<version>.zip` として作る

## 実行例

PowerShell から次を実行する。

```powershell
.\tools\Create-ReleasePackage.ps1
```

成功時の出力先は次である。

- 展開済みパッケージ: `artifacts/release/StretchViewCS-1.0.0.0/`
- zip パッケージ: `artifacts/release/StretchViewCS-1.0.0.0.zip`

## 手動確認項目

パッケージ作成後は、少なくとも次を確認する。

1. `StretchViewCS.exe` が起動する
2. `環境設定` が開く
3. `ヘルプ` が `help/index.html` を開く
4. 保存済み設定が `%AppData%\StretchViewCS\StretchViewCS.ini` に書かれる
5. `ホットキー無効` の既定値やサンプリングレート既定値が期待どおりである

## Inno Setup インストーラー

Inno Setup によるインストーラー定義を追加している。

- [StretchViewCS.iss](/C:/repos/StretchViewCS/installer/StretchViewCS.iss)
- [Build-InnoInstaller.ps1](/C:/repos/StretchViewCS/tools/Build-InnoInstaller.ps1)

このインストーラーは次を行う。

- `StretchViewCS.exe` と必要ファイルを `{autopf}\StretchViewCS` に配置する
- `help/` を同梱する
- スタートメニューショートカットを作成する
- 任意タスクとしてデスクトップショートカットを作成できる
- インストール完了後にアプリを起動できる

### 前提

Inno Setup 6 をインストールして、`ISCC.exe` が使える状態にする。

標準インストール先の例:

- `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`
- `C:\Program Files\Inno Setup 6\ISCC.exe`

### 実行例

PowerShell から次を実行する。

```powershell
.\tools\Build-InnoInstaller.ps1
```

成功時の出力先は次である。

- `artifacts/installer/StretchViewCS-Setup-1.0.0.0.exe`

## インストーラー確認項目

インストーラー作成後は、少なくとも次を確認する。

1. インストール先に配布対象ファイルだけが配置される
2. スタートメニューショートカットから起動できる
3. デスクトップショートカットを選択した場合だけ作成される
4. `help/` がインストール先に含まれる
5. アンインストールできる
