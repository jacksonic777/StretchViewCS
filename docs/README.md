# StretchView (C#版)

Delphiで書かれたStretchViewアプリケーションをVisual C#に変換したプロジェクトです。

## プロジェクト構成

```
StretchViewCS/
├── StretchViewCS/
│   ├── Program.cs              # エントリーポイント
│   ├── app.manifest            # アプリケーションマニフェスト
│   ├── Native/
│   │   └── Win32API.cs         # Windows API P/Invoke定義
│   ├── Utils/
│   │   ├── IniManager.cs       # INIファイル管理
│   │   └── XRotateBitmap.cs    # 画像回転処理
│   └── Forms/
│       ├── frmCap.cs           # メインフォーム
│       ├── frmCap.Designer.cs  # メインフォームデザイナー
│       ├── frmSetting.cs       # 設定フォーム
│       ├── frmHelp.cs          # ヘルプフォーム
│       ├── frmVersion.cs       # バージョン情報フォーム
│       └── frmLicense.cs       # ライセンスフォーム
└── README.md
```

## 必要な環境

- Visual Studio 2022 以降
- .NET Framework 4.8
- Windows 10/11

## ビルド方法

1. Visual Studioで `StretchViewCS.csproj` を開く
2. ソリューションをビルド（Ctrl+Shift+B）

## 注意事項

1. **不完全な実装**: このプロジェクトは基本的な構造と主要な機能の骨組みを提供していますが、完全な機能実装には追加の作業が必要です。

2. **パフォーマンス**: 画像回転処理は現在Graphics.Transformを使用した簡易版です。元のDelphiコードと同等のパフォーマンスが必要な場合は、低レベルピクセル操作版の実装が必要です。

3. **ホットキー**: ホットキー登録機能は現在コメントアウトされています。実装する場合は、`RegisterMyHotkeys()` メソッドを完成させてください。

4. **INIファイル**: INIファイルの読み書きは `System.Configuration` を使用していますが、元のDelphiコードとは形式が異なる可能性があります。必要に応じて調整してください。

## 既知の問題・未完了

- ホットキーは登録処理が無効のため、キー操作では動作しない
- 印刷はダイアログ表示までで、実際のプinter 出力は未実装
- 画像回転は簡易版のため、必要に応じて LockBits 最適化の余地あり
