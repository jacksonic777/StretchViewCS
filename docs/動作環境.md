# 動作環境

## 対象

このドキュメントは、Windows版 `StretchViewCS` の動作環境を整理する。

## 結論

現行のWindows版 `StretchViewCS` は、Windows専用アプリケーションとして扱う。

- アプリ本体は `.NET Framework 4.8` の WinForms アプリである。
- 画面取得、デスクトップ描画、ウィンドウ操作、ホットキーなどで Win32 API を利用する。
- そのため、現行のWindows版をそのまま macOS / Linux で実行することは想定しない。

## 推奨動作環境

通常利用と配布対象としては、次を推奨する。

- OS: Windows 10 22H2 以降、または Windows 11
- CPU: x64
- ランタイム: .NET Framework 4.8 以上
- 画面: デスクトップアプリを表示できる通常のWindowsデスクトップ環境

## 動作可能と考えられる環境

Microsoftの.NET Framework 4.8対応OS上であれば、アプリ本体の起動条件は満たせる可能性がある。

- Windows 11
- Windows 10
- Windows Server 2022
- Windows Server 2019
- Windows Server 2016
- Windows Server 2012 R2
- Windows Server 2012

ただし、StretchViewCSは画面キャプチャやデスクトップ操作を主用途とするため、Windows Server環境ではデスクトップセッション、権限、リモートデスクトップ条件によって一部機能の挙動が変わる可能性がある。

## 非推奨または対象外

次の環境は、現行の配布・動作確認対象から外す。

- macOS
- Linux
- Wine / Proton などの互換レイヤー
- Windows 7 / Windows 8.1
- Windows 10 のサポート終了済みバージョン
- Windows Server のサポート終了済みバージョン

`.NET Framework 4.8` 自体は古いWindowsにもインストール可能な場合があるが、OS側のサポートが終了している環境はリリース対象に含めない。

## インストーラーの前提

Inno Setup版インストーラーは、次を前提とする。

- 管理者権限でインストールする。
- 64bit Windowsでは `Program Files` 側にインストールする。
- スタートメニューショートカットを作成する。
- オプション選択時のみデスクトップショートカットを作成する。

## 開発・ビルド環境

開発とリリース作成では、次を前提とする。

- Visual Studio 2022
- .NET Framework 4.8 Developer Pack
- MSBuild
- Inno Setup 6
- PowerShell

## 根拠

- `StretchViewCS.csproj` は `TargetFramework` に `net48`、`UseWindowsForms` に `true` を指定している。
- `Native/Win32API.cs` で Windows API を利用している。
- `installer/StretchViewCS.iss` は Inno Setup によるWindowsインストーラー定義である。
- Microsoft Learn の .NET Framework system requirements では、.NET Framework 4.8 の対応Windowsが整理されている。

Windows依存機能の詳細は [Windows依存機能](./Windows依存機能.md) を参照する。
