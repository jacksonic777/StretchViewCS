StretchViewCS ReadMe
====================

概要
----
StretchViewCS は、画面の一部を拡大、縮小、回転、反転しながら確認するための Windows アプリケーションです。
本ソフトウェアはフリーソフトです。

主な機能
--------
- 画面上の対象範囲の選択とミラーリング表示
- 表示倍率の変更、原寸以下への縮小表示
- 左右反転、上下反転、回転
- 方眼、中心線、カラーピッカー（座標、HEX、RGB、色プレビュー表示）
- 表示画像の保存、クリップボードコピー、簡易印刷
- 日本語 / 英語の表示切り替え

設定ファイル
------------
設定は次の場所に保存されます。

%AppData%\StretchViewCS\StretchViewCS.ini

初回起動時は、Windows の表示言語に応じて日本語または英語を自動設定します。

ホットキー
----------
ホットキーは初期状態では無効です。
必要な場合は、アプリの設定画面で有効にしてください。

ヘルプ
------
アプリの「ヘルプ」メニューからローカルHTMLヘルプを開けます。
表示言語に応じて、日本語版または英語版のヘルプを開きます。

ライセンス
----------
StretchViewCS はフリーソフトです。利用料なしで使用できます。
フリーソフト表記は、著作権の放棄やパブリックドメイン化を意味するものではありません。
再配布や転載を行う場合は、配布元の案内と同梱ドキュメントを確認してください。
