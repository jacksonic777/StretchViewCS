# StretchViewCS

StretchViewCS は、画面の一部を拡大、縮小、回転、反転しながら確認するための Windows アプリケーションです。
本ソフトウェアはフリーソフトです。

## 主な機能

- デスクトップ上の対象範囲を選択してミラーリング表示
- 表示倍率の変更と原寸以下への縮小表示
- 左右反転、上下反転、左右回転、回転リセット
- 方眼、中心線、ウィンドウサイズプリセット
- カラーピッカーによる座標、HEX、RGB、色プレビュー表示
- 表示画像の保存、クリップボードコピー、簡易印刷
- 日本語 / 英語の表示切り替え

## 動作環境

- Windows 10 22H2 以降、または Windows 11 を推奨
- .NET Framework 4.8
- 画面キャプチャ、カラーピッカー、ホットキーなどで Win32 API を使用します

## 使い方

1. `StretchViewCS.exe` を起動します。
2. 必要に応じて「対象範囲の選択」で表示したい画面範囲を指定します。
3. ツールバーやメニューから拡大、縮小、反転、回転、方眼表示などを操作します。
4. ヘルプメニューからローカル HTML ヘルプを開けます。

## 設定

設定画面は、ツールメニューの「設定..」またはメインウィンドウ上部の「設定」ボタンから開けます。

- 初回起動時は、Windows の表示言語に応じて日本語または英語を自動設定します。
- ホットキーは初期状態では無効です。
- サンプリングレートの初期値は 400 ms です。
- 対象範囲の選択状態は、初期状態では起動時に復元しません。
- 設定は `%AppData%\StretchViewCS\StretchViewCS.ini` に保存されます。

## 廃止済み機能

表面レイヤ機能と画面定規機能は廃止済みです。現行版では通常操作の対象として扱いません。
