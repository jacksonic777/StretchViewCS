StretchViewCS ヘルプ

StretchViewCS は、画面の一部を拡大、縮小、回転、反転しながら確認するための Windows アプリケーションです。 このヘルプでは、基本操作と主要機能をまとめています。

概要

StretchViewCS は、デスクトップ上の選択範囲をメインウィンドウに表示し、見やすい倍率や角度に調整するための補助ツールです。 細かな表示確認、画面の一部の追跡、画像としての保存に利用できます。

使いどころ

  • 資料、画面共有、レビュー中に、画面の一部を大きく表示して細部を確認できます。
  • UI、画像、図面などを左右反転、上下反転、回転して、見え方の違いや配置の崩れを確認できます。
  • 対象範囲を固定すると、別アプリの一部を見ながら作業できます。
  • カラーピッカーで、画面上の色を HEX / RGB として確認してコピーできます。

対象範囲

  • 「対象範囲の選択」からミラーリング対象の画面範囲を指定できます。
  • 対象範囲の赤い枠線は、ドラッグで位置や大きさを調整できます。
  • 対象範囲の固定化は、メニューまたはチェックボックスから切り替えます。
  • Ctrl + 方向キーで、選択済みの対象範囲を移動できます。
  • 「対象範囲の選択」は、初期状態では起動時に OFF です。起動時に復元したい場合は、設定画面で「対象範囲の選択を起動時に復元」を有効にしてください。

表示操作

機能 説明
拡大 / 縮小 表示倍率を変更します。原寸以下の縮小表示にも対応しています。
拡縮リセット 表示倍率をリセットします。
左右反転 / 上下反転 表示内容を水平または垂直方向に反転します。
回転 左右回転、指定角度回転、回転リセットを行います。
方眼 / 中心線 表示確認用の目盛や中心線を重ねて表示します。
最前面表示 メインウィンドウを他のウィンドウより手前に表示します。チェックボックスから切り替えられます。
ウィンドウサイズ 表示メニューから、200x200、300x300 などのプリセットサイズを選べます。

ツール

  • カラーピッカーで、デスクトップ上の色を取得してクリップボードへコピーできます。
  • カラーピッカー情報フォームには、カーソル位置の座標、HEX、RGB、色プレビューが表示されます。
  • カラーピッカー中は、左クリックで色コードをコピーし、Esc キーで終了します。

設定

  • 設定画面は、ツールメニューの「設定..」またはメインウィンドウ上部の「設定」ボタンから開けます。
  • 設定画面から表示言語を日本語または英語に切り替えられます。
  • ホットキーは初期状態では無効です。必要な場合だけ設定画面で有効にしてください。
  • サンプリングレートの初期値は 400 ms です。設定画面から変更できます。値を小さくすると更新頻度が上がります。
  • 対象範囲の選択状態を次回起動時に復元するかどうかを設定できます。初期状態では復元しません。
  • スタートメニューへの登録を設定できます。
  • 設定は `%AppData%\StretchViewCS\StretchViewCS.ini` に保存されます。

保存と出力

  • 現在の表示画像をファイルに保存できます。
  • 現在の表示画像をクリップボードへコピーできます。
  • 簡易印刷機能から印刷ダイアログを開けます。

廃止済み機能

  • 表面レイヤ機能は廃止済みです。現行版ではメニューやツールバーから利用しません。
  • 画面定規機能は廃止済みです。現行版ではメニューやツールバーから利用しません。
  • 操作投影モードは安定版の通常操作対象から外しています。相手先アプリへ確実に操作を反映する用途には使用しないでください。

困ったとき

  • ヘルプが開かない場合は、アプリと同じ場所に `help` フォルダがあるか確認してください。
  • ホットキーが効かない場合は、設定画面でホットキーが有効か確認してください。
  • 対象範囲が追従しない場合は、対象範囲の選択状態と固定化状態を確認してください。
  • 表示が重い場合は、サンプリングレートを大きめの値に戻してください。
