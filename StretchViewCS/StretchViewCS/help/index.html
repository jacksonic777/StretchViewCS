StretchViewCS ヘルプ

StretchViewCS は、画面の一部を拡大して見やすくするための Windows アプリケーションです。 このページでは、基本操作とよく使う機能をまとめています。

概要

StretchViewCS は、デスクトップ画面の一部を拡大表示し、必要に応じて回転、反転、固定表示などを行うためのツールです。 作業中のウィンドウを見やすく確認したいときや、細かな表示を追いたいときに使います。

基本操作

まずはここから

メニューから必要な機能を選び、表示内容や拡大率を調整してください。

  • マウスで操作しながら、表示内容を確認できます。
  • メニューから拡大、縮小、回転、反転などの機能を切り替えられます。
  • 画像の保存やクリップボードへのコピーを行えます。
  • 必要に応じて印刷関連の機能を利用できます。

固定表示

固定表示モードでは、表示対象となるウィンドウを指定して、その内容を継続的に追いかけられます。 固定したい対象をアクティブにしてから、アプリの固定表示機能を使ってください。

固定表示を解除したい場合は、同じ機能をもう一度実行して解除します。

ホットキー

ホットキーは初期状態では無効です。利用する場合は、設定画面で有効化してください。

キー 操作
Ctrl+A ズームアップ
Ctrl+S ズームダウン
Ctrl+D 左右反転
Ctrl+F 上下反転
Ctrl+E 固定表示の切り替え

設定と保存

  • 設定画面から各種動作を変更できます。
  • ホットキーの有効、無効は設定画面から切り替えられます。
  • 設定内容やウィンドウ状態は、次回起動時に復元されることがあります。

困ったとき

  • ホットキーが効かない場合は、設定画面で有効になっているか確認してください。
  • 期待した対象が表示されない場合は、固定表示や表示対象の選択状態を確認してください。
  • ヘルプが開かない場合は、`help` フォルダがアプリと同じ場所に配置されているか確認してください。
