StretchViewCS Help

StretchViewCS is a Windows application for viewing part of the screen with zoom, shrink, rotation, and flip controls. This help file explains the basic workflow and the main features.

Overview

StretchViewCS mirrors a selected desktop area into the main window and lets you adjust the view with zoom, rotation, and flip operations. It is useful for checking small details, tracking part of the screen, and saving the current view as an image.

Target Range

  • Use Selection Range to choose the screen area to mirror.
  • The red target-range frame can be dragged to adjust its position and size.
  • Use the menu item or checkbox to enable or disable fixed target range mode.
  • Use Ctrl + arrow keys to move the selected target range.

View Controls

Feature Description
Zoom in / Zoom out Changes the display scale. Shrinking below the original size is supported.
Reset zoom Resets the display scale.
Flip horizontally / vertically Flips the current view horizontally or vertically.
Rotation Rotates left or right, rotates by a custom angle, or resets rotation.
Grid / center lines Overlays grid lines or center lines for visual checking.

Tools

  • The color picker samples a desktop color and copies the color code to the clipboard.
  • The screen ruler measures width and height on the desktop in pixels.
  • The surface layer lets you draw temporary notes over the main view.

Settings

  • You can switch the display language between Japanese and English in Settings.
  • Hotkeys are disabled by default. Enable them in Settings only when needed.
  • The default sampling rate is 400 ms. It can be changed in Settings.
  • Settings are saved to `%AppData%\StretchViewCS\StretchViewCS.ini`.

Save and Output

  • You can save the current view as an image file.
  • You can copy the current view to the clipboard.
  • You can open the print dialog from the quick print feature.

Troubleshooting

  • If help does not open, check that the `help` folder exists next to the application.
  • If hotkeys do not work, confirm that hotkeys are enabled in Settings.
  • If the target range does not follow changes, check the range selection and fixed range state.
