StretchViewCS ReadMe
====================

Overview
--------
StretchViewCS is a Windows application for viewing part of the screen with zoom, shrink, rotation, and flip controls.

Main Features
-------------
- Select and mirror a target area on the desktop
- Change the display scale, including shrinking below the original size
- Flip horizontally, flip vertically, and rotate
- Grid lines, center lines, screen ruler, and color picker
- Temporary drawing on the surface layer
- Save the current view, copy it to the clipboard, and use quick print
- Japanese / English display language switching

Settings File
-------------
Settings are saved to:

%AppData%\StretchViewCS\StretchViewCS.ini

Hotkeys
-------
Hotkeys are disabled by default.
Enable them in the application settings only when needed.

Help
----
You can open the local HTML help from the Help menu.
StretchViewCS opens the Japanese or English help file according to the current display language.

Uninstall
---------
If StretchViewCS was installed with the installer, uninstall it from Windows Apps or from the Start menu uninstall item.
